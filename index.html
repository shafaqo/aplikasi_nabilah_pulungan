Panduan Penggunaan Aplikasi

Langkah-langkah Menggunakan Aplikasi

  1. Login menggunakan username dan PIN masing-masing. Contoh: username sarina, PIN sarina.
  2. Pilih menu Kasir (POS) untuk memasukkan transaksi penjualan layanan dan produk.
  3. Gunakan menu Arus Kas untuk mencatat pemasukan dan pengeluaran selain POS.
  4. Pilih menu Homecare untuk melihat dan mengelola order layanan homecare dari pelanggan.
  5. Pilih menu Stok Barang untuk memeriksa dan memperbarui inventaris gudang.
  6. Untuk melihat ringkasan dan cetak laporan, buka menu Laporan Data. Catatan: menu ini memerlukan sandi tambahan.
  7. Untuk backup atau restore data, buka menu Pengaturan. Catatan: menu ini juga dilindungi sandi.
  8. Selalu klik Keluar jika selesai menggunakan aplikasi agar sesi login tidak tersimpan.

Tips & Catatan

  • Pastikan perangkat memiliki kapasitas penyimpanan yang cukup untuk menyimpan data aplikasi.
  • Gunakan fitur backup secara berkala untuk mengamankan data penting.
  • Jika mengalami kesulitan, hubungi tim support melalui kontak resmi klinik. 0822-7390-2728 Ahmad Ro'pat

Tampilan Halaman Login

Tampilan awal aplikasi yang menunjukkan area login untuk masuk ke sistem, silahkan masukkan username masing-masing pada form yang disediakan.

Tampilan Menu Kasir

Tampilan menu kasir yang menampilkan opsi transaksi dan produk. view bawaan etalase produk itu mode grid dan bisa diubah menjadi mode daftar. melalui tombol atau slider di sebelah atas yang ditunjuk mouse atau pointer.

Tentang Aplikasi

Aplikasi ini dirancang untuk membantu pengelolaan kasir dan administrasi klinik secara offline dengan fitur laporan, inventaris, homecare, serta backup/restore data. Digunakan dalam operasional sehari-hari Rumah Amara Holistic Care.

  • Versi: 1.0.5
  • Kemampuan: POS, arus kas, homecare, inventory, laporan PDF/CSV, backup lokal, restore data, sinkronisasi cloud.
  • Lisensi: Hak cipta dilindungi.
